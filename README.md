# moggmon-assets

Downloadable CC0 Moggmon Gen 1 reference assets for moggmon.com.

- `assets/sprites/gen1`: sprite PNGs and JSON atlases
- `assets/characters/gen1`: first-frame character PNGs
- `assets/models/gen1`: GLB models and support files when complete
- `manifest.json`: generated asset index consumed by moggmon.com

All assets in this repository are released as CC0.
